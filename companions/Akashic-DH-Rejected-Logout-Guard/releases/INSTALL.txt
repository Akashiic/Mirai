Instalação:

2. MANTENHA Akashic-DH-Logout-Lifecycle-Fix-1.0.1-serveronly.jar instalado.
3. Adicione Akashic-DH-Rejected-Logout-Guard-1.0.0-serveronly.jar em /mods.
4. NÃO instale este patch no cliente, Velocity, Paper/lobby ou /plugins.
5. Ligue o Crucible novamente; não use /reload ou hot reload.

Sinais esperados no boot:
- Akashic DH Rejected Logout Guard 1.0.0 armed (server-only; Forge/Crucible 1.7.10).

Quando uma conexão incompleta for rejeitada, pode aparecer:

O patch NÃO torna um cliente incompatível compatível. Ele impede que uma rejeição FML
com lifecycle incompleto derrube o servidor dentro do listener de logout do Horizons.
